Camera-Only Optical Protocol & Morse End Marker

1. Multi-Base Conversion & Fixed 0.1s/bit Optical Clock:

  • Your text is converted live into Hexadecimal, Octal, and Final UTF-8 Binary.
  • Every bit is flashed at an exact 0.1s (100 ms) rate: 1 = Flash ON (75 ms + 25 ms gap), 0 = Flash OFF (100 ms).

2. Reserved Morse Code End-of-Transmission (SK: · · · — · —):

  • Wake Beacon: 0.3s solid flash + 0.1s dark gap alerts the camera.
  • Sync Header: 10101010 11110000 locks the 0.1s clock (nothing is written until locked).
  • Length + Payload + CRC-16: 16-bit byte length, exact UTF-8 binary, and 16-bit CRC checksum.
  • Reserved Morse SK End: International Morse End-of-Transmission prosign ···—·— (101010111010111) with smooth 0.3s dashes tells the receiver the message has ended and triggers immediate text decoding.

3. Running on Two Phones:

  • Open this same HTTPS link on both phones. Tap Start Receiver and Calibrate Ambient on Phone B while Phone A is dark, then tap Start Flash on Phone A and aim during the 3-second countdown.
