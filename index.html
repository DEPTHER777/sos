0.1s Protocol & Two-Device Setup Guide

Fixed 0.1s (100 ms) Bit Clock:

  • Every bit takes exactly 0.1 seconds (100 ms) on both phones—no manual speed matching required.
  • Bit 1 = Flash ON / Beep ON (75 ms pulse + 25 ms guard gap).
  • Bit 0 = Flash OFF / Silent (100 ms).

Exact Frame Structure:

  • Wake Beacon: 300 ms solid pulse + 100 ms gap to alert the receiver.
  • Preamble + SOF: 10101010 11110000 (16 bits). Receiver writes nothing until locked.
  • Length: 16-bit UTF-8 byte count.
  • Payload: Exact UTF-8 binary of your message (e.g. Hello = 40 bits).
  • CRC-16 + EOF: 16-bit checksum + 00001111 end marker.

Quick Two-Device Steps:

  • Open this same HTTPS link on Phone A (Transmitter) and Phone B (Receiver).
  • On Phone B, select Optical or Audio, tap Start Receiver, then tap Calibrate Ambient while Phone A is silent/dark.
  • On Phone A, type Hello and tap Start. Use the 3-second countdown to aim or position the phones.
